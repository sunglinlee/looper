∞ Looper 隱私權政策

最後更新：2026-10-08

Looper（以下簡稱「本擴充功能」）是一個在 YouTube 影片頁面上提供 AB 段落循環、節拍器與速度偵測的瀏覽器擴充功能。

1. 我們蒐集的資料

本擴充功能不蒐集、不儲存、不傳送、不販售任何個人資料或瀏覽資料，也沒有任何伺服器或第三方分析服務。

2. 音訊分析

「自動偵測 BPM」與「對齊拍點」功能會讀取 YouTube 影片正在播放的音訊，用來估算速度與拍點。這些分析完全在你的瀏覽器本機即時完成，音訊不會被錄製、儲存或上傳到任何地方。

3. 本機儲存的設定

本擴充功能只會在你的瀏覽器本機（localStorage）記住以下設定：面板位置、介面語言、面板是否縮小、重複次數計數的開關。這些設定不會離開你的裝置。

4. 權限

本擴充功能僅在 www.youtube.com 頁面上執行，沒有申請其他瀏覽器權限。

5. 第三方

本擴充功能與 YouTube、Google 無關聯，也不與任何第三方分享資料。

6. 政策變更

若政策有變更，會更新本頁並修改上方日期。

7. 聯絡方式

如有問題，請到 GitHub Issues 留言。

∞ Looper Privacy Policy

Last updated: 2026-10-08

Looper (the "Extension") is a browser extension that adds an A-B loop, metronome and tempo detection to YouTube video pages.

1. Data we collect

The Extension does not collect, store, transmit or sell any personal or browsing data. It has no servers and uses no third-party analytics.

2. Audio analysis

The "Auto detect" and "Beat sync" features read the audio of the video that is currently playing in order to estimate tempo and beat positions. This analysis happens entirely and in real time inside your browser. Audio is never recorded, stored or uploaded anywhere.

3. Locally stored settings

The Extension only remembers the following in your browser's local storage: panel position, interface language, whether the panel is minimized, and the repeat-counter toggle. These settings never leave your device.

4. Permissions

The Extension runs only on www.youtube.com pages and requests no other browser permissions.

5. Third parties

The Extension is not affiliated with YouTube or Google and shares no data with any third party.

6. Changes

If this policy changes, this page and the date above will be updated.

7. Contact

Questions: please open an issue on GitHub Issues.
