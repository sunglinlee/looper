# ∞ Looper

YouTube 練琴用的 Chrome 擴充功能：AB 段落循環、節拍器、自動偵測 BPM。
A Chrome extension for practicing along with YouTube: A-B loop, metronome and tempo detection.

## 功能 / Features

- **AB 循環 / A-B loop**：設 A、B 點自動重播，±0.1 秒微調，可開關的重複次數計數
- **快捷鍵 / Shortcuts**：`[` 設 A、`]` 設 B、`\` 開關循環
- **速度 / Speed**：0.25x – 1.5x
- **節拍器 / Metronome**：30–300 BPM、拍號、音量、Tap tempo
- **自動偵測 BPM、對齊拍點 / Auto tempo detection and beat sync**：全部在瀏覽器本機分析
- 可拖曳面板、縮成右下角小按鈕、中英文介面切換

## 安裝（開發版）/ Install (unpacked)

1. 開啟 `chrome://extensions` 並啟用「開發人員模式」
2. 點「載入未封裝項目」，選擇本專案資料夾
